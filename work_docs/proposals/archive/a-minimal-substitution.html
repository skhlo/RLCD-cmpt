Throwaway prototype - not production code

Does the minimal substitution drop the right memories?

An agent keeps a small set of written records about a work session. When there are too many, a “dropper” deletes some of them. Today a chat model picks which ones. This prototype replaces that pick with a TypeSafe judgment, and leaves everything else exactly as it is: the same limit on how many may go, the same ranking, the same fallback. The question it answers: with the model reduced to two numbers per record, does the right thing still get dropped, and does a load-bearing record ever slip through? Press the buttons and watch the records.

Every number shown in blue is a hard-coded simulation of what the TypeSafe model (Jev) would return. No network calls are made. Token counts and the memory budget are scaled down so the arithmetic is visible; the real budget is 20,000 tokens.
