Does reranking put the answer on page one?

Today recall ranks session history with BM25 and shows the agent five results per page out of a shortlist capped at fifty. This demo asks one question: when the agent searches for something it genuinely needs, does the answer land on page one, and does judged relevance move it there? Drive it with the free-play controls, or take the guided walkthroughs, which push the model through the cases that are hard to reason about on paper. The interesting ones are the failures: an answer the keyword search cannot see at all, a rerank that never happens, and a memory pool that grows without the compacted summary growing with it.
